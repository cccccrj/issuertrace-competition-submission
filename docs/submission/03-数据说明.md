数据时间范围按2026-09-04历史盘点记录：自采统计跨度2024-01-02至2026-09-04，主办方语料统计跨度2026-01-01至2026-05-29。该范围属于对应历史盘点；本次快照规模采用上表及字段清单。来源配置见 [sources.yaml](../../config/sources.yaml)。S0为政府、交易所、法院等权威原始来源；S1为公司官网、公告镜像及授权问答；S2为独立媒体和行业媒体；S3为转载与聚合平台。来源层级评价权威性，来源独立性结合转载聚类与传播关系另行评价。

本轮GPU实验使用上述快照的93209段证据及3922条主张，输入文件SHA256及段落指纹与冻结向量快照一致。受控输入在独立GPU实验环境的.private目录使用，报告仅分发输入摘要、编号／分数、性能采样与聚合效果；不向Git新增原始正文或模型权重。新近邻在独立目录完成导入和效果复核，现有运行快照中的裁决与近邻保持原样。

## 2 关键字段含义

| 字段组 | 意义 |
|---|---|
| document_id / version_id / content_hash | 文档标识、内容版本、原始内容哈希；通过哈希区分同URL的内容版本 |
| company_id / source_id / source_tier | 目标公司、来源站点、S0～S3证据等级；来源等级和来源独立性分别评价 |
| published_at / published_basis / fetched_at | 发布时间、时间推断来源、采集时间，三个维度独立存储 |
| raw_path / extraction_status / inclusion_status | 原始文件位置、解析结果、是否进入分析；跨环境复现按配置恢复相应路径 |
| event_id / event_types_json / event_time / label_source | 事件、类型集合、发生时间、模型或规则标签来源 |
| raw_text / normalized_value / unit / basis / status | 要素原文、归一值、单位、口径与归一状态 |
| claim_id / source_start / source_end | 原子主张和连续原文定位跨度 |
| verdict / partial_subtype / method / confidence | 四值核验、部分支持原因、方法、模型置信度；校准正确率按独立评价统计 |
| evidence_version_id / evidence_page / evidence_text | 被引用披露版本、页码、证据原文 |
| issue_id / issue_code / status | 持续事项实体、事项类别及生命周期状态 |
| alert_id / level / risk_score | 机器预警、等级、分数；人工判断另存处置表 |
| username / role / recipient / actor / decided_at | 账号、角色、收件人、人工操作者、记录时间；提交快照用新比赛账号 |

## 3 预处理

保留原始内容及版本 → 正文解析（HTML/PDF等）→ 排除列表页、接口响应、无正文和非目标内容 → 时间与公司解析 → 规则守门 → 模型事件抽取 → 原文跨度校验 → 数量／币种／期间归一 → 披露段落索引 → 主张裁决与派生关系。

检索体做繁简折叠、中文二元组和拉丁词切分；展示与引用保留原文措辞。披露段落承担事实核验依据，行情和市场反应提供辅助对照；因果分析按专项识别协议评价。采集与解析状态完整留存，支持覆盖率复核及样本追溯。

## 4 脱敏与发布控制

部署快照不是生产数据库原样复制。SQLite backup取得一致副本后，删除原生产账号哈希、人工复核／任务／分派、人工处置与审计、订阅与投递、通知与阅读记录、人工事项调整，并创建5个新的比赛账号。随后VACUUM清除空闲页中的旧哈希。源数据库不修改；清理表清单随证据提交。

发布控制已隔离密钥、真实.env、原账号配置、机器访问日志和个人会话Cookie。公开文档中的公司名、人名及原文引用按来源保留，以支持实体识别和证据查证；非公开个人材料按独立审核与脱敏流程接入。

## 5 使用限制与复现边界

自采文本和公开披露的权利归原权利人，主办方评测数据按比赛授权使用。交付采用私有仓库授权或指定材料渠道，第三方数据的再利用按相应授权执行；公开镜像、商业分发与第三方转交需另行取得许可。

运行包提供已解析证据段落、结构化结果、处理后的主办方评测数据、匹配的检索近邻、前端和数据库，可直接运行原型并查看已有实验。正文片段属于处理后内容，保留必要公司、日期、来源URL及公开披露信息以支持证据追溯。处理后业务库与评测库独立保存，配套索引按段落指纹匹配，支持直接部署与评审复核。
