# IssuerTrace V1.0 演示材料

正式演示附件在同一V1.0 Release统一提供：

- [答辩PPT：IssuerTrace-V1.0-presentation.pptx](https://github.com/cccccrj/issuertrace-competition-submission/releases/download/v1.0/IssuerTrace-V1.0-presentation.pptx)，30页。
- [演示视频：IssuerTrace-V1.0-demo.mp4](https://github.com/cccccrj/issuertrace-competition-submission/releases/download/v1.0/IssuerTrace-V1.0-demo.mp4)，193.577秒，约3分14秒，符合3—5分钟要求。

两个文件仅统一文件名，内容保持原样，视频不裁剪、不重新编码。已完成PPT文件结构、视频时长与完整解码、文件摘要和抽样画面核验。视频展示风险事项、证据与人工处置、研判助手、时间线、主张与披露比对及核验看板等流程。

文件大小与SHA256见[media-manifest.json](media-manifest.json)。源码、正式报告、运行包和演示附件统一对应V1.0，全部发布附件纳入SHA256SUMS；展示快照与各项实测按各自数据、环境和评价口径阅读，完整结论见[测试报告](05-测试报告.md)。

在空目录下载并校验：

```bash
gh release download v1.0 --repo cccccrj/issuertrace-competition-submission \
  --pattern 'IssuerTrace-V1.0-presentation.pptx' \
  --pattern 'IssuerTrace-V1.0-demo.mp4' --pattern SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS
```

私有仓库访问需相应GitHub权限，或通过比赛指定材料渠道取得附件。部署入口见[部署与访问](01-部署与访问.md)。
