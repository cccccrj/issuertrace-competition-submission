# 处理后数据交付范围

交付版本：v1.0。仓库与Release保持私有。

## 完整处理后数据

- 业务快照：文档与版本元信息、已解析正文与证据段落、事件及要素、主张与裁决、重复簇、传播关系、版本差异、问询、事项及机器状态、风险提醒、行情和财务指标。
- 评测快照：处理后的主办方文章、事件标签及定义，独立保存于benchmark.sqlite3，与平台业务事实库分别统计。
- 检索配套：与证据段落编号及指纹匹配的近邻文件和manifest，保留引用来源、公开公司身份及时间等必要字段。

业务存于collector.sqlite3，评测存于benchmark.sqlite3，近邻存于data/state/dense/。同一私有仓库Release提供运行包，随附文件大小及SHA256；完整表计数与字段见[03数据说明](03-数据说明.md)及[data-inventory.json](evidence/data-inventory.json)。

## 脱敏与使用

运行包采用清理后的分析快照和全新评审身份。生产用户与密码散列、真实人工操作、通知投递、订阅、会话及实例密钥均已按发布清理流程隔离；SQLite副本完成完整性核验与VACUUM。公开公司事实、来源URL及证据文本按追溯需要保留。

处理后内容按对应来源授权用于本次比赛评审；公开镜像、商业再分发或第三方转交遵循各自许可。文件摘要、段落指纹与源码标签共同记录交付对应关系，历史业务与GPU实测证据保持原样。
